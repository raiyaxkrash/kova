Архитектура

Нативный стек без лишних прослоек

Rust + Tauri 2 + Win32

Интерфейс работает на системном WebView2, а процессы, реестр автозапуска и перехват клавиш вызывают Win32 API напрямую.

Прямые релизы GitHub

Никаких промежуточных серверов. Kova проверяет публичный GitHub API и скачивает официальные сборки напрямую из репозиториев.

Автозапуск и UAC

Единое управление ключами реестра, запуск с правами администратора для системных хуков и сворачивание в трей.

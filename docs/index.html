ИНЖЕНЕРИЯ

Сделано без компромиссов по ресурсам

01

Нативный Rust + Win32

Никаких тяжёлых Electron-сборок на 150 МБ. Kova и все утилиты собраны на Rust с системным WebView2 и прямыми вызовами Win32 API.

02

Без сторонних серверов

Лаунчер общается напрямую с публичным GitHub API, проверяет свежие релизы и скачивает официальные артефакты прямо из репозиториев.

03

Единый автозапуск и трей

Включай и отключай автозапуск Windows, отслеживай запущенные процессы и обновляй все четыре инструмента из одного окна.
